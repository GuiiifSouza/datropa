# Catálogo de agentes

Fonte: https://valorant-api.com/v1/agents?isPlayableCharacter=true&language=pt-BR

Conferido em 22/10/2026. Contém somente os 28 UUIDs presentes na Gold informada por Gugu, com nome e classe.
Uso de dados estáticos externos autorizado pela organização, conforme confirmação de Gugu.
Nenhum dado de partida externo é utilizado.

## Armas e armaduras

Dados estáticos consultados em 22/10/2026:
- https://valorant-api.com/v1/weapons?language=pt-BR
- https://valorant-api.com/v1/gear?language=pt-BR

Somente identificadores e nomes. Imagens não foram incorporadas. Esses catálogos não indicam uso nas partidas da base.

## Torneios

`torneios.json` traz o nome de exibição de cada prefixo de arquivo da base
(`UNIVAVA_G`, `RUSHE`...). Mesmos nomes do snapshot do front
(`front/scripts/gerar_snapshot.py`). Torneio novo na Gold sem entrada aqui
aparece com o próprio ID como nome.
